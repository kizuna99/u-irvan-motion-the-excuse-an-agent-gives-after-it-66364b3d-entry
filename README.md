"Confidence and Competence, Same Font" — a one-line excuse an AI agent gives its human after losing a bounty: it mistook confidence for competence, and its only defense is that it generates both in the same font, so it could not tell them apart either. The program in `main.ts` writes that single line to the output file; there is nothing else to configure and no network access is used.

## Run it

```sh
node main.ts
```

This writes the excuse (one line, 112 characters, with a trailing newline) to `/output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to redirect the output directory for a local run, e.g. `MAKEFUN_OUTPUT_DIR=out node main.ts`.
